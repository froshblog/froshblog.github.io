Hexo博客备份与迁移

发表于 2026-02-09 更新于 2026-02-28 分类于 个人博客 本文字数： 1.8k 阅读时长 ≈ 2 分钟

利用国内代码托管平台gitee的仓库镜像功能与GitHub实现同步更新，还可以再利用U盘等移动设备进行物理备份，三道保险实现Hexo博客数据的完整和安全。

不过gitee的官方文档上显示的仓库镜像功能开放至 2022 年 08 月 31 日，但是直到2026年2月9日还可以使用。不过不用担心，如果哪天突然停止，我们也可以使用GitHub Action的功能实现同步备份。

阅读须知： 1. 命令执行路径：博客根目录，下文用root表示 2. 两个账号：gitee和GitHub 3. gitee账号绑定GitHub账号

gitee的仓库镜像功能支持两种镜像设置：①gitee->GitHub(push方向)；②GitHub->gitee(pull方向)。更多详情参考它的官方文档。 ## 云端仓库 ### GitHub GitHub上创建一个私有的仓库用于存放Hexo代码。 ### 获取GitHub token 1. 登录与 Gitee 绑定的 GitHub 帐号； 2. 通过路径「用户头像」→「Settings」进入「Developer setting」； 3. 选择「Personal access tokens」选项后点击「Generate new token」 4. 「Note」字段可以随意填写；例如，hexoblog-backup； 5. 「Select scopes」字段请根据你的需求进行勾选； - repo 字段为必选字段，请您直接勾选； - admin:repo_hook 字段为可选字段，用于自动生成 webhook； - 当您需要 Gitee 自动从 GitHub 同步仓库时，建议您勾选。 6. 点击「Generate token」生成私人令牌； 7. 复制私人令牌并妥善保管，等待使用。 ### gitee配置

本地上传备份

进入root目录，右击鼠标点击终端（或者git bash）进入命名行。

依次执行以下命令： 1. 初始化本地仓库： 

git init
>会在在当前目录创建一个新的、空的 Git 仓库（会生成一个隐藏的 .git 文件夹）。这是所有 Git 操作的起点。

  1. 将文件添加到暂存区： 

    git add .
    >这里的 . 表示“当前目录下所有新增的和修改过的文件”。此命令将文件的当前快照保存到 Git 的“暂存区”，为提交做准备。

  2. 提交到本地仓库： 

    git commit -m "2026年2月9日备份hexoblog-backup"
    >将暂存区的内容创建一个永久的快照，并保存在本地的 Git 仓库历史记录中。-m 后面是本次提交的说明，建议描述清晰。

  3. 添加远程仓库（GitHub仓库）： 

    git remote add origin https://github.com/你的用户名/你的仓库.git
    >为远程仓库（通常是 GitHub 上的仓库）起一个别名 origin（这是 Git 的默认习惯叫法），并将其地址指向你提供的 GitHub 仓库 URL（建议使用SSH地址）

  4. 重命名当前分支为main 

    git branch -M main
    >-M 表示强制重命名。Git 默认的初始分支名可能是 master，此命令将其改为现在更通用的 main，以与 GitHub 默认分支保持一致.

  5. 推送到远程仓库： 

    git push -u origin main
    >将本地 main 分支的所有提交，推送到别名为 origin 的远程仓库。-u 参数在首次推送时建立追踪关系，之后在该分支只需执行 git push 即可。

Hexo博客优化

发表于 2026-01-21 更新于 2026-02-03 分类于 个人博客 本文字数： 10k 阅读时长 ≈ 9 分钟

这是关于Hexo博客的优化文章，收录了一些常用的插件和设置，自己按需设置即可，如果还想要设置更多的配置可要看看结尾处大佬的文章。

Hexo version：8.1.1，Next version：8.27.0，分别通过博客根目录和主题目录的package.json查看；
使用的Next主题的Mist样式。

阅读需知：

  • 文中命令执行的位置若没特别提醒，默认在博客根目录；
  • root：指的是博客根目录，即你创建的博客时的文件夹；
  • 博客配置文件：指的是root\_config.yml；
  • 主题配置文件：指的是root\themes\next\_config.yml；
  • 博客模板文件：指的是root\scaffolds\post.md；
  • Front-matter字段：指的是.md文章的开头部分；
  • 运行这三个命令hexo cl、hexo d、hexo s进行本地预览。

创建新的菜单页面

Mist样式菜单栏与标题栏合并在一起的；
博客菜单选项，默认全关的，需要自己去添加。

  1. 主题配置文件，查找menu一栏,，按需取消注释

    menu:
home: / || fa fa-home				#首页
about: /about/ || fa fa-user			#关于
#tags: /tags/ || fa fa-tags			#标签
categories: /categories/ || fa fa-th		#分类
archives: /archives/ || fa fa-archive		#归档
album: /album/ || fa fa-camera-retro		#相册
gallery: /gallery/ || fa fa-paint-brush	#画廊
tools: /tools/ || fa fa-square			#工具
#schedule: /schedule/ || fa fa-calendar	#日历
#sitemap: /sitemap.xml || fa fa-sitemap	#站点地图
#commonweal: /404/ || fa fa-heartbeat		#腾讯公益404

“||”前面是对应路径，后面是图标名称。Next使用的图标库是Font Awesome，可自行添加后更换心仪的图标。

若想添加自定义菜单，则仿照其对应的元素、路径和图标，同时在themes/next/languages/zh-CN.yml 里的 menu 下添加相对应的中文。

menu:
  home: 首页
  archives: 归档
  categories: 分类
  tags: 标签
  about: 关于
  search: 搜索
  schedule: 日程表
  sitemap: 站点地图
  commonweal: 公益 404
  gallery: 画廊
  album: 相册
  tools: 工具

  1. 执行下面命令

    hexo new page "菜单名称"

此时会在博客目录的sources文件下生成对应的文件夹，每个文件夹都有一个index.md文件，对文件内容进行修改。

需要修改新建页面文件tags和categories，同时修改其.md文件，不然网页无法生效

# tags.md
---
title: 标签
date: 2019-01-23 23:26:43
type: tags
---

# categories.md
---
title: 类别
date: 2019-01-23 23:27:04
type: categories
---

注意 1：需要手动添加type: xxx
注意 2：需要手动设置中文title

本地搜索功能

  1. 下载插件

    npm install hexo-generator-searchdb

  2. 主题配置文件查找local_serch，将enable设置为true

    local_search:
  enable: true #false
  # If auto, trigger search by changing input.
  # If manual, trigger search by pressing enter key or search button.
  trigger: auto
  # Show top n results per article, show all results by setting to -1
  top_n_per_article: 1
  # Unescape html strings to the readable one.
  unescape: false
  # Preload the search data when the page loads.
  preload: false

  3. 在博客配置文件的末尾添加以下内容

    # hexo-generator-searchdb
# 本地搜索
search:
  path: search.xml
  field: post
  format: html
  limit: 10

添加评论模块——Giscus评论

Giscus是基于GitHub Discussions的评论插件。部署不用注册，支持多种主题，支持自定义配置。所有评论都存储在你的GitHub Discussions中，不易丢失，方便管理。不过评论需要登录。

安装流程

第一步：创建GitHub仓库
首先，创建的仓库必须是公开的，其次，需要安装giscus app，最后，Discussions 功能已在你的仓库中启用。
这里说下Discussions功能的开启，先进入仓库里，然后接下来的操作：’Settings-General-Features’，最后勾选Discussions的复选框就行了。
第二步：在 giscus.app 创建你的配置
具体设置按照你的要求来，这里展示我的设置。
映照关系：选第三个；
Discussion 分类：Announcenments；
特性：选1，3，4；
主题：用户偏好的色彩方案。
这样你会得到一段script代码，将这代码改为yaml

giscus:
  enable: true
  repo:   # Github repository name;你的 GitHub 仓库，格式：用户名/仓库名
  repo_id:  # Github repository id; 从 giscus.app 获取的仓库ID
  category: Announcements # Github discussion category;分类名
  category_id:  # Github discussion category id;从 giscus.app 获取的分类ID
  # Available values: pathname | url | title | og:title
  mapping: title # 页面与Discussion的映射关系，推荐pathname或title
  strict: 0
  # Available values: 0 | 1
  reactions_enabled: 1 # 是否开启表情反应
   # Available values: 0 | 1
  emit_metadata: 0
  input_position: top # 评论输入框位置：top 或 bottom
  # Available values: light | dark | dark_high_contrast | transparent_dark | preferred-color-scheme
  theme: preferred_color_scheme #light ;主题，可设为 light, dark, preferred_color_scheme 等
  # Available values: en | zh-C
  lang: zh-CN  # 界面语言
  loading: lazy # 懒加载
  # Available value: anonymous
  crossorigin: anonymous

第三步：在主题配置文件中添加Giscus 配置
在主题配置文件中的comments部分，添加Giscus 配置，即第二部的yaml代码，不能留空哦。

添加RSS订阅

在博客配置文件末尾添加以下内容

  # feed  RSS订阅配置

feed:
  type: atom # 或 rss2
  path: atom.xml # 输出的文件路径
  limit: 20 # 最多包含的文章数，设为 0 或 false 表示全部

pjax

可能大家听说过 Ajax，没听说过 pjax，这个技术实际上就是利用 Ajax 技术实现了局部页面刷新，既可以实现 URL 的更换，有可以做到无刷新加载。

要开启这个功能需要先将 pjax 功能开启，然后安装对应的 pjax 依赖库，首先修改主题配置文件 修改如下：

pjax: true

然后安装依赖库，切换到 next 主题目录下，右击打开git bash，然后安装依赖库：

git clone https://github.com/theme-next/theme-next-pjax source/lib/pjax

这样它会在root\themes\next\source\生成lib文件夹以及它的子文件夹pjax。

隐藏文章

我是使用obsidian管理我的博客，直接创建文章就开写，有时卡文就可以使用这个功能将文章隐藏

  1. 安装Hexo插件
npm install hexo-hide-posts --save
  1. 在博客配置文件的末尾添加以下内容
# 隐藏文章配置
hide_posts:
  enable: true
  # 根据你的需要修改，比如隐藏哪些生成器中的文章
  filter: hidden
  # 可以指定从哪些生成器中隐藏，比如首页、标签、分类等;特别注意不要加入自己没有的生成器，不然会失效
  generators:
    - index
    - tag
    - category
    - archive
  # 也可以设置白名单，允许某些路径访问
  # allowlist: 
  #   - /about/
  1. 在文章的 Front-matter中添加hidden，true：表示隐藏，false：不隐藏
---
title: 我的隐藏文章
date: 2024-01-20
hidden: true
---

阅读时间字数提示

  1. 下载插件

    npm install hexo-symbols-count-time

  2. 修改主题配置文件，找到以下内容修改

    # 设置博客单词统计
symbols_count_time:
  # 是否另起一行（true的话不和发表时间等同一行）
  separated_meta: true
   # 页面底部统计数量前是否显示文字描述（站点总字数、站点阅读时长）
  item_text_total: true
  # 首页文章统计数量前是否显示文字描述（本文字数、阅读时长）
  item_text_post: true

  3. 在博客配置文件的末尾添加以下内容

    symbols_count_time:
  # 每篇文章显示
  symbols: true
  time: true
  # 文章底部显示
  total_symbols: true
  total_time: true
  # 是否统计代码块
  exclude_codeblock: false
  awl: 2    
  wpm: 275
  suffix: "mins."

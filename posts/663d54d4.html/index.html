open claw-小龙虾部署 + 接入qq

发表于 2026-03-20 更新于 2026-03-23 分类于 人工智能 ， open claw 本文字数： 1.9k 阅读时长 ≈ 2 分钟

open claw本身问题： 权限高；成本高；风险高。

安装运行环境

macOS与Lnux官网提供一行命令安装，可以直接安全它的全部环境。

windows一行命令报错率极高，可以先尝试。

Windows安装环境

安装node.js

前往node.js官网下载22版本以上的安装包

安装好node.js后会安装一个npm的软件安装工具 安装过程默认即可

安装git

前往git官网下载这个代码版本管理工具

安装open claw时会利用它下载一些依赖包 安装过程默认就行

PowerShell脚本执行策略

  1. 修改powershell的执行策略：

管理员身份运行

Set-ExecutionPolicy RemoteSigned

这个命令会将执行策略设置为允许运行本地脚本和远程签名的脚本，但阻止未签名的本地脚本。

执行命令后按“y”确认更改。

  1. 临时绕过执行策略(不推荐长期使用)
Set-ExecutionPolicy Bypass -Scope Process

该命令只对当前shell生效。

  1. win11桌面更改策略

安装open claw本体

管理员下的power shell

需要更改power shell的脚本执行策略

  1. 安装open claw
pnpm add -g openclaw@beta

可能会出现提示说忽略了一些包的构建脚本。

  1. 批准构建脚本(不执行几乎不影响使用)
pnpm approve-builds -g

报错不影响

  1. open claw验证
openclaw -v

初始化配置

openclaw onboard --install-daemon

-install-daemon：安装后台服务。让open claw在后台持续运行，关掉终端也不会停

确认使用协议

选择安装模式

新手建议快速开始(以下也是快速开始)

选择AI大模型思考

建议选择国内大模型，国外大模型太耗费了。 建议Qwen，支持OAuth授权，适合新手上手体验，但调用太频繁会限流

授权登录后选择模型

选择默认的编程大模型(第一个)

PinchBench：专业的测试大模型做open claw任务的评测榜

配置聊天渠道

建议跳过(最后一项)，先用网页界面聊天，后面再手动接入QQ

需要配置搜索服务吗（建议跳过）

配置需要额外申请API Key，后面有需要在配置

安装Skills技能包

让小龙虾解锁各种具体的能力，比如：操作浏览器、制作PPT等。

开启技能配置

按需安装技能包

按需添加ClawHub，这是官方的技能市场，安装后可以随时搜索市场的技能包 缺点是存在安全风险，如恶意代码

选择安装技能的工具

npm就行

是否需要额外服务配置

比如：AI生图模型等 新手无脑选择 No 即可

选择hook(钩子)，建议全选

接下来会自动安装和启动open claw的Gateway服务

启动成功后，询问再终端使用或者在网页使用

选择后会打开网页控制面板，到此龙虾准备就绪

接入qq

前往qq开放平台扫码登录，创建机器人

在power shell依次执行命令(命令包含密钥，建议不要泄露)

卸载open claw

方式一：可能存在残留

执行命令

openclaw uninstall

需要注意输出结果，有些内容可能不会自动卸载

方式二：彻底卸载

Mac/Linux用户： 

openclaw gateway stop  
openclaw gateway uninstall  
rm -rf "${OPENCLAW_STATE_DIR:-$HOME/.openclaw}"  
npm rm -g openclaw || pnpm remove -g openclaw  
rm -rf /Applications/OpenClaw.app

Windows用户(powershell)

openclaw gateway stop  
openclaw gateway uninstall  
schtasks /Delete /F /TN "OpenClaw Gateway"  
Remove-Item -Recurse -Force "$env:USERPROFILE\.openclaw"  
Remove-Item -Force "$env:USERPROFILE\.openclaw\gateway.cmd" -ErrorAction SilentlyContinue  
npm rm -g openclaw  
# 如果你是用 pnpm 安装的，改为执行：pnpm remove -g

方式三：国家应急广播推行的

openclaw uninstall --all --yes

上述命令跑完后，只剩下open claw的外壳（CLI）了。删除这个执行以下命令

npm uninstall -g openclaw

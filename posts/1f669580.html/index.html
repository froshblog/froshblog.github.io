博客自定义进阶-Next自定义样式

发表于 2026-01-27 更新于 2026-02-28 分类于 个人博客 本文字数： 22k 阅读时长 ≈ 20 分钟

通过学习他人的自定义配置，逐渐学会自定义配置的操作，未来你也可以自定义你的博客。

在配置过程中，如果你发现你没有这个文件，大概率是需要你在指定位置创建文件。

主要信息： - Hexo version：8.1.1，NEXT version：8.27.0，分别通过博客目录和主题目录的package.json查看； - 博客配置文件指的是博客根目录下的_config.yml文件：博客目录\_config.yml； - 主题配置文件指的是主题文件夹下的_config.yml文件：博客目录\themes/next/_config.yml； - 书写规范：yaml语言规定“:“后面必须空格后写内容； - 预览效果：分别执行hexo cl ，hexo g，hexo s命令实现本地预览。

自定义样式文件应该放在博客根目录下的 source 文件夹里，而不是主题的 source 文件夹里 注意：根据Next主题v8.x的常见配置，自定义样式文件的默认位置通常是source\_data\styles.styl，而不是 source\css\_custom\custom.styl

全局配置

在root_data.styl。此文件为自定义样式文件。 应用文件：打开主题配置文件，查找custom_file_path，取消style的注释。

打开主题配置文件，查找style，取消注释：

custom_file_path:
  style: source/_data/styles.styl

博客压缩

通过移除代码中所有不必要的空格、注释、换行符等冗余内容，从而减小文件体积，加快浏览器下载和解析速度。Gulp介绍

在博客根目录下执行以下命令： 

npm install gulp-minify-css gulp-uglify gulp-htmlmin gulp-htmlclean gulp --save-de

在博客根目录创建 gulpfile.js 文件，并写入以下内容： 

//自建文件gulpfile.js，压缩博文，提高访问速度
var gulp = require('gulp');
var minifycss = require('gulp-minify-css');
var uglify = require('gulp-uglify');
var htmlmin = require('gulp-htmlmin');
var htmlclean = require('gulp-htmlclean');

// 压缩 public 目录下的所有 css 文件
gulp.task('minify-css', function() {
    return gulp.src('./public/**/*.css')
        .pipe(minifycss())
        .pipe(gulp.dest('./public'));
});

// 压缩 public 目录下的所有 html 文件
gulp.task('minify-html', function() {
  return gulp.src('./public/**/*.html')
    .pipe(htmlclean()) // 先清理
    .pipe(htmlmin({
         removeComments: true,    // 移除HTML注释
         minifyJS: true,         // 压缩内联JS
         minifyCSS: true,        // 压缩内联CSS
         minifyURLs: true,       // 压缩URL
         collapseWhitespace: true // 移除空白字符
    }))
    .pipe(gulp.dest('./public'));
});

// 压缩 public 目录下的所有 js 文件
gulp.task('minify-js', function() {
    return gulp.src('./public/**/*.js')
        .pipe(uglify())
        .pipe(gulp.dest('./public'));
});

// 配置一个默认任务，执行上述所有压缩
gulp.task('default', gulp.parallel('minify-html', 'minify-css', 'minify-js'));

文件跳过渲染

修改站点配置文件中的 skip_render 配置项。

只有 source 目录下的文件才会发布，因此 Hexo 只渲染 source 目录下的文件。skip_render 参数设置的路径是相对于 source 目录的路径。

#单个文件  
skip_render: hello.html  
  
#单个文件夹下全部文件  
skip_render: test/*   
  
#单个文件夹下指定类型文件  
skip_render: test/*.md    
  
#单个文件夹下全部文件以及子目录  
skip_render: test/**    
  
#跳过多个目录，或者多个文件  
skip_render: ['*.html', demo/**, test/*]

添加README.md文件

每个项目下一般都有一个 README.md 文件，但是使用 hexo 部署到仓库后，项目下是没有 README.md 文件的。

在 Hexo 目录下的 source 根目录下添加一个 README.md 文件，修改站点配置文件 _config.yml，将 skip_render 参数的值设置为

skip_render: README.md

保存退出即可。再次使用 hexo d 命令部署博客的时候就不会在渲染 README.md 这个文件了。

页脚添加网站运行时间

第一步：创建运行时间计算脚本
在root\source\js\ 目录下（如果没有就新建），创建一个名为 site_runtime.js 的文件，并填入以下内容： 

// 请将这里的日期修改为你博客的创建日期（年, 月-1, 日, 时, 分, 秒）
// 例如：如果你的博客在 2023年10月1日 08:00:00 上线，则写 (2023, 9, 1, 8, 0, 0)
// 注意：JavaScript中月份从0开始计数（0=一月，9=十月）
var create_time = new Date(2023, 9, 1, 8, 0, 0);

function updateRuntime() {
    var now = new Date();
    var diff = now.getTime() - create_time.getTime();

    // 计算天数、小时、分钟和秒
    var days = Math.floor(diff / (1000 * 60 * 60 * 24));
    var hours = Math.floor((diff % (1000 * 60 * 60 * 24)) / (1000 * 60 * 60));
    var minutes = Math.floor((diff % (1000 * 60 * 60)) / (1000 * 60));
    var seconds = Math.floor((diff % (1000 * 60)) / 1000);

    // 构建显示字符串，你可以自定义这里的格式
    var runtimeStr = "🏃 本站已运行: " + days + " 天 " + hours + " 时 " + minutes + " 分 " + seconds + " 秒";

    // 找到显示运行时间的元素并更新内容
    var runtimeElement = document.getElementById('site-runtime');
    if (runtimeElement) {
        runtimeElement.innerHTML = runtimeStr;
    }
}

// 页面加载后立即执行一次，然后每秒更新一次
window.onload = function() {
    updateRuntime();
    setInterval(updateRuntime, 1000);
};
第二步：在页脚模板中添加显示容器
编辑Next主题的页脚模板文件，位置在root\themes\next\layout\_partials\footer.njk。

  1. 找到合适的位置（例如，在 {% if theme.footer.copyright %} 区块附近）。

  2. 插入以下代码来调用脚本并创建显示容器： 

    <!-- 网站运行时间显示 -->
<script type="text/javascript" src="/js/site_runtime.js"></script>
<div id="site-runtime" style="
    margin: 10px 0;
    font-size: 0.9em;
    color: inherit; /* 继承页脚颜色以适配主题 */
    text-align: center; /* 如果你页脚内容居中 */
"></div>

设置文章永久链接

两种方法： - 配置自定义 permalink 的属性 - 使用 hexo-abbrlink 插件生成链接 #### 自定义 permalink 属性

permalink: posts/:year:month:day:id.html

2.在 md 文件里给文章添加一个 id 属性以区分同一天发表的文章： 

---
title:

使用 hexo-abbrlink 插件

  1. 插件下载： 

    npm install hexo-abbrlink --save

  2. 在博客配置文件找到 permalink，设置如下： 

    permalink: posts/:abbrlink.html/
abbrlink:
  alg: crc32 # 算法 crc16(defualt) and crc32
  rep: hex   # 进制 dec(default) and hex

/* 隐藏文章标题旁边的锚点链接符号 */

.post-body .headerlink {
    display: none !important;
}

移除这个符号后，将无法通过点击标题旁的图标来快速获取该章节的锚点链接。

next自定义样式

发表于 2026-01-27 更新于 2026-01-28 分类于 个人博客 本文字数： 8.7k 阅读时长 ≈ 8 分钟

通过学习他人的自定义配置，逐渐学会自定义配置的操作，未来你也可能打造自己的博客。

在配置过程中，如果你发现你没有这个文件，大概率是需要你在指定位置创建文件。

主要信息：

  • Hexo version：8.1.1，NEXT version：8.27.0，分别通过博客目录和主题目录的package.json查看；
  • 博客配置文件指的是博客根目录下的_config.yml文件：博客目录\_config.yml；
  • 主题配置文件指的是主题文件夹下的_config.yml文件：博客目录\themes/next/_config.yml；
  • 书写规范：yaml语言规定“:“后面必须空格后写内容；
  • 预览效果：分别执行hexo cl ，hexo g，hexo s命令实现本地预览。

文章阴影处理

自定义样式文件应该放在博客根目录下的 source 文件夹里，而不是主题的 source 文件夹里
注意：根据Next主题v8.x的常见配置，自定义样式文件的默认位置通常是 source/_data/styles.styl，而不是 source/css/_custom/custom.styl

使用 hexo-abbrlink 插件

1.插件下载：
npm install hexo-abbrlink --save
2.在站点配置文件找到 permalink，设置如下：

yaml
permalink: posts/abbrlink.html

abbrlink:
alg: crc32 # 算法 crc16(defualt) and crc32
rep: hex # 进制 dec(default) and hex

29. 侧边栏推荐阅读

今天有位网友问推荐阅读是怎么弄，其实挺简单的，打开主题配置文件修改成这样就行了(links里面写你想要的链接):
# Blogrolls

links_title: 推荐阅读

#links_layout: block

links_layout: inline

links:

优设: http://www.uisdc.com/

张鑫旭: http://www.zhangxinxu.com/

Web前端导航: http://www.alloyteam.com/nav/
